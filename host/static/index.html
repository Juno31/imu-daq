Equipment configuration

Global orientation in the jig NOT DONE

All IMUs sit in the jig with the same orientation, jig still on a level table. The capture averages each IMU's quaternion and compares it with the reference IMU. With the game rotation vector the heading is set when an IMU starts: do not restart the IMUs between this capture and the recordings.

Keep the jig still…

Six-face sensor calibration  optional · per board

Accelerometer bias, scale and axis alignment, gyroscope bias. Warm up 10–15 min, then record the jig on each of its 6 faces, still for ≥ 15 s per face (any order). Stop, then analyse.

IMU attachment & data quality —

Body segment comes from the Spine view's sensor placement. Tick each IMU when attached and secured; the live columns must be green before you continue.

Static calibration  after the IMUs are attached

aStill holdNOT DONE

Participant stands still in the neutral posture: upright, looking ahead, arms relaxed.

Hold still…
bForward bendNOT DONE

Sets the body's left–right axis for spine angles. Right after the still hold, without turning the feet: bend forward slowly (40° or more), then come back up.

EMG attachment & data quality —

Prepare the skin (shave, abrade, alcohol), place the electrodes along the fibres, then check each channel at rest (low RMS, no clipping, not floating) and with a short contraction (clear burst).

Devices all green before the participant arrives · click a tile for detail

Time sync test NOT RUN

Records a short test trial (task synctest) with every device, then checks that every IMU frame has exactly one SYNC pulse on the DAQ.
